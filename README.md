# Online Morse Code Translator

> The most complete free Morse code platform on the web —
> translate, listen, learn, decode, and practice.

**[onlinemorsecode.com](https://onlinemorsecode.com)**

---

## What is this?

[Online Morse Code Translator](https://onlinemorsecode.com) is a free,
no-signup web platform with 10+ Morse code tools, full A–Z and 0–9
character references, 17 world language scripts, prosign support,
and an interactive CW learning academy.
